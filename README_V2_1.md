# V2.1 — Clasificación y comprensión

Esta rama evoluciona el observatorio desde un detector de diferencias hacia un historial comprensible de cambios en documentos legales y de confianza.

El sistema separa tres dimensiones: el **tipo de documento** que se vigila, las **materias afectadas** por cada modificación y la **relevancia automática** que ayuda a priorizar su revisión. Cada registro conserva el diff exacto y el enlace al documento oficial, pero presenta primero un resumen breve en lenguaje sencillo.

La arquitectura está preparada para vigilar términos y condiciones, términos de servicio, políticas de privacidad, condiciones de licenciamiento, acuerdos de tratamiento de datos, documentación de seguridad/cumplimiento y otros documentos legales configurados por el administrador.

La ampliación de empresas se realizará después de validar esta capa de clasificación y la fiabilidad de las fuentes actuales.
