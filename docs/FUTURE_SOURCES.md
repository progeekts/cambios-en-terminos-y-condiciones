# Futuras fuentes

La V2.1 no amplía deliberadamente el catálogo de empresas. Antes se validarán la clasificación, los resúmenes y la robustez de las fuentes existentes.

Cuando se abra la siguiente fase, las candidatas se evaluarán por utilidad pública, relevancia del servicio, disponibilidad de documentos oficiales, estabilidad técnica de las páginas y existencia de versiones regionales diferenciadas.

La prioridad no será alcanzar el mayor número de empresas, sino mantener un catálogo verificable que pueda revisarse de forma automática con una tasa de error razonablemente baja.
