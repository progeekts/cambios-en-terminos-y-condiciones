# Cambios de V2.1

## Clasificación

El motor diferencia el tipo de documento de las materias detectadas dentro de cada modificación. El clasificador incorpora seguridad, cumplimiento, cuentas/acceso y categorías legales y de privacidad ya existentes.

## Comprensión

Los registros nuevos incluyen un resumen descriptivo en lenguaje sencillo y mantienen el diff exacto como evidencia verificable. La interfaz muestra primero el resumen y deja el diff plegado.

## Consulta

La portada permite buscar y filtrar por empresa, tipo de documento, materia y relevancia.

## Extensibilidad

Se documentan siete familias de documentos y se añade un esquema de configuración para futuras fuentes. La ampliación de empresas queda fuera de esta fase.

## Transparencia

Se añade una página pública de metodología, documentación del clasificador, catálogo público de categorías, versionado del esquema y pruebas automáticas.
