# V2.2 — Fiabilidad y cobertura

Esta fase endurece el monitor antes de ampliar de forma significativa el catálogo de empresas.

## Motor

- Reintentos con espera progresiva ante errores de red.
- Validación del tipo de contenido recibido.
- Detección básica de páginas de bloqueo, CAPTCHA y desafíos anti-bot.
- Protección frente a reducciones o expansiones anómalas del documento para evitar sustituir un snapshot válido por una página técnica.
- Hash SHA-256 del contenido limpio para evitar comparaciones innecesarias.
- Soporte opcional de selector CSS por fuente.
- Fuentes configurables mediante `enabled`.
- Estado individual de cada documento en `docs/status.json`.

## Web

- Bloque “Cambios importantes recientes” para modificaciones de relevancia Alta o Media.
- Indicador de fuentes procesadas correctamente.
- Resumen de incidencias y cambios de la última revisión.
- Acceso visible a metodología, glosario y preguntas frecuentes.

## Siguiente paso

Ejecutar el monitor con fuentes reales, estudiar los diagnósticos individuales y ajustar cada fuente problemática antes de incorporar nuevas empresas a gran escala.
