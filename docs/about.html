Cómo funciona el observatorio

El objetivo es registrar modificaciones de documentos públicos y hacerlas más fáciles de localizar y comprender, manteniendo siempre disponible el cambio exacto.

1. Documentos

El administrador configura documentos oficiales públicos. Pueden ser términos y condiciones, términos de servicio, políticas de privacidad, condiciones de licenciamiento, acuerdos de tratamiento de datos, documentación de seguridad o cumplimiento y otros documentos legales.

2. Detección

En cada comprobación se obtiene el documento y se compara su texto con la versión almacenada anteriormente. Si existen diferencias, se conserva una representación de las líneas añadidas y eliminadas.

3. Clasificación

Un clasificador basado en reglas busca señales relacionadas con materias como datos personales, IA, terceros, transferencias internacionales, conservación, publicidad, licencias, disputas, jurisdicción, pagos, derechos del usuario, seguridad y cumplimiento.

4. Explicación sencilla

El sistema construye un resumen descriptivo a partir de las materias detectadas. Está diseñado para indicar de qué parece tratar el cambio, no para determinar sus consecuencias jurídicas.

Importante

Las categorías, resúmenes y niveles de relevancia son resultados automáticos orientativos. Pueden contener errores o no detectar todos los matices. Para verificar un cambio debe consultarse el diff y el documento oficial enlazado.

5. Relevancia

Alta, Media y Baja sirven únicamente para ordenar y priorizar la revisión. No indican que una modificación sea favorable, perjudicial, legal o ilegal.

Cómo confirmamos un cambio

Una diferencia detectada no se publica automáticamente como un cambio legal. Primero se valida la respuesta de la fuente, se elimina ruido técnico conocido y se compara el contenido normalizado. Si aparece una versión distinta, queda pendiente de confirmación. Solo se publica cuando esa misma versión persiste en una comprobación posterior; si la fuente vuelve a la versión estable, se descarta como variante transitoria.

Las fechas de versión se muestran únicamente cuando están declaradas expresamente por la fuente. La fecha de comprobación del observatorio y la fecha de un cambio confirmado son datos distintos.
