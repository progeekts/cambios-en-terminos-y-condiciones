# Criterios para nuevas fuentes

Antes de añadir un documento al observatorio debe comprobarse que pertenece a una fuente oficial de la empresa o servicio, es públicamente accesible, identifica con claridad qué documento representa y puede recuperarse de forma suficientemente estable para comparar versiones.

No debe añadirse una URL únicamente porque contenga información legal. Es preferible monitorizar el documento canónico publicado por la organización.

Si existen versiones distintas por región o idioma, deben tratarse como fuentes diferenciadas cuando su contenido jurídico sea diferente. Los campos opcionales `region` y `language` están previstos para esta evolución.

Las páginas que requieran autenticación, devuelvan contenido personalizado o utilicen mecanismos que impidan obtener de forma fiable el documento deben quedar pendientes hasta disponer de una estrategia de captura verificable.
