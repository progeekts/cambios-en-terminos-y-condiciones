# Principios de calidad

1. **Fuente antes que resumen.** Todo registro debe mantener el enlace al documento oficial y el cambio textual disponible.
2. **Describir antes que interpretar.** Los resúmenes automáticos explican materias detectadas sin atribuir consecuencias jurídicas no verificadas.
3. **Separar documento y materia.** Una política de privacidad puede cambiar por precios, IA, seguridad u otras materias; ambos ejes deben poder consultarse de forma independiente.
4. **Compatibilidad histórica.** Las mejoras del modelo de datos no deben hacer ilegibles los registros anteriores.
5. **Escalar con control.** Se incorporarán nuevas empresas después de comprobar la estabilidad de las fuentes y del sistema de detección.
