# Aviso sobre la información mostrada

El observatorio registra automáticamente diferencias detectadas en documentos públicos enlazados desde sus fuentes oficiales.

Los resúmenes, categorías y niveles de relevancia se generan mediante reglas automáticas y tienen una finalidad informativa y de organización. No constituyen asesoramiento jurídico ni determinan por sí mismos el significado, validez o efecto legal de una modificación.

Puede haber cambios que el sistema no clasifique correctamente, contenido dinámico que produzca diferencias técnicas o matices que solo sean apreciables leyendo el documento completo. Por este motivo se conserva el diff disponible y se enlaza la fuente oficial para facilitar la verificación.
