# Datos JSON públicos

La web se publica como sitio estático, por lo que sus ficheros JSON pueden reutilizarse directamente por otras herramientas.

- `diffs.json`: registros históricos de cambios.
- `status.json`: resultado de la última revisión.
- `catalog.json`: taxonomía general.
- `categories.json`: materias y descripciones.
- `document-types.json`: familias documentales.
- `relevance.json`: significado de los niveles de relevancia.
- `schema-version.json`: versiones actuales del esquema, clasificador y observatorio.

No se garantiza todavía estabilidad contractual de estos ficheros como una API pública. El versionado incorporado permitirá formalizarla en una fase posterior.
